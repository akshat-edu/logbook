A simple study tracker I made for keeping track of JEE preparation. (made in June uploading here to help others lol XD)

I wanted something where I could quickly see what I've studied, what I still have left, and how much progress I'm actually making, without having to maintain a notebook, or in simple words- to digitalize jee preparation even more :D   

DEMO: https://logbookjee.netlify.app/

## What it is log book

Logbook lets you keep track of your preparation across:

- 📐 Mathematics
- ⚛️ Physics
- 🧪 Chemistry

You can mark chapters as completed, keep track of your progress, and use the dashboard to get a quick idea of where you stand.

The main idea is pretty simple:

> **Study → log it → see the progress → repeat.**

## Why I made it

I was using a mix of notes, lists and random trackers to keep track of my preparation, and honestly, none of them felt particularly useful.

I wanted something that was:

- quick to update
- easy to understand
- actually nice to look at
- usable on both laptop and phone
- completely mine

Using the knowledge I gained in CS from my school, I decided to build this project. Though started as a small self help project, I decided that it will help millions of JEE Aspirants all over India! 

## How I made it

First of all, I designed a clear mind map of what is going to be included in the tool and how am I going to add..... then I coded the first draft with no UI or any other thing and then did some perfections and boom it was ready, but there were some problems like the site kept on resetting the data by itself, there was no UI, so I took help from various AI models and drafted them into one singular piece of code and turning that thought into a reality !!!

Long story short AI I gave the initial code and transformed it into perfection with no bugs and an *aesthetic* UI😍.

There isn't a backend. Logbook is lightweight and runs directly in the browser.

## Running it locally

There's no complicated setup.

Clone the repository:

```bash
git clone https://github.com/akshat-edu/logbook.git
```

Then open `index.html` in your browser.

That's it.

## A few things I'm learning from this

This was one of my first projects where I tried to make something that I'd actually use myself and help others instead of just following a tutorial.

It also taught me a lot about:

- organizing a frontend project
- working with JavaScript data
- making interfaces responsive
- thinking about how users actually interact with a tool
- fixing things that looked fine in my head but definitely weren't fine in the browser 😭
- Using AI in your code is not a bad thing, using AI to fully code is wrong where you learn nothing from it.
